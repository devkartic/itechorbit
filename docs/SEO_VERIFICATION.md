# SEO and data compatibility verification

The route baseline and migration schema are recorded in ROUTES_BASELINE.json and SCHEMA_BASELINE.md. Article paths `/blogs/{id}`, category paths `/blogs/category/{id}` and profile paths `/portfolios/{key}` retain their concrete URLs. Parameter names changed internally, not public paths. POST `/blogs/search` remains accepted, and GET search is added. Friendly About/Contact/Blog aliases redirect with 301. `/services` remains the protected legacy admin resource; public service details use allow-listed `/services/{slug}` paths.

Removed resource routes were declarations with empty legacy handlers: blog/profile CRUD, newsletter CRUD except subscription, contact create/edit/update, comment index/create/show. They were not working content pages. The Sanctum cookie route is omitted by route:list's vendor filter; inspect with `--include-vendor` when comparing. No working public article/profile URL was intentionally removed. The homepage now presents the agency, with the blog list at its existing `/blogs` URL.

Public React pages use Inertia SSR. Browser tests request HTML independently of JavaScript and verify headings, canonical links and article JSON-LD. Titles use Inertia's escaped title property; hostile-title fixtures verify that markup cannot escape into the head. Search/tag results are noindex; public pagination has page-specific canonicals. Sitemap indexes split record lists into 10,000 URL chunks and include published articles/projects/enabled portfolios, excluding private records and admin routes. Robots is served dynamically; the previous static robots file is retained in docs/ROBOTS_BASELINE.txt. Do not restore it into public/ or it will shadow Laravel's route.

Release still requires complete live URL and media inventory, crawl comparison, Search Console review, verified canonical host/HTTPS, and representative content inspection on a restored staging dataset. Source and synthetic tests cannot establish production record/media preservation. No SEO launch is approved by these checks alone.

Live read-only discovery now captured 110 URL strings, including 49 article paths, across the homepage, its three pages and the sitemap (LIVE_URL_SAMPLE.txt). Legacy root pagination permanently redirects to `/blogs?page=N`; the new homepage does not silently absorb old list pages. This is a discovered URL set, not proof of every production URL.
